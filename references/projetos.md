# Projetos

Leia quando a pessoa participa de pesquisa (IC, mestrado, doutorado), extensão, ensino ou
desenvolvimento tecnológico, ou quando precisa ligar produções a um projeto.

## Ideia central

Projeto é o **projeto real** (o do orientador ou do grupo), com o título oficial. "Iniciação
Científica", "PIBIC" ou "Mestrado" **não são projetos**. O vínculo de bolsista diz *que* a
pessoa tem bolsa; o projeto diz *em que* ela trabalha e liga as produções ao trabalho.

## Caminho e campos (manual CNPq 2026)

**Projetos › "Projeto de pesquisa"** (ou de extensão, ensino, desenvolvimento tecnológico,
outros) **› "Incluir novo item"**.

| Campo | O que pôr |
|---|---|
| "Nome do projeto" | Título oficial completo, como no edital/sistema da universidade |
| "Descrição" | Objetivos e tema do projeto + uma frase sobre o papel da pessoa |
| "Natureza" | Pesquisa / Extensão / Ensino / Desenvolvimento tecnológico / Outra |
| "Situação" | **Em andamento** (sem ano de fim), **Interrompido** ou **Concluído** (início e fim) |
| Período | Só anos (AAAA) |
| "Instituição de execução" | A universidade, pela lupa |
| "Órgão/Unidade" | Instituto/faculdade/departamento |
| "Pesquisadores" (integrantes) | O coordenador marcado como **coordenador**; a pessoa como integrante. Inclua outros membros se quiser |
| "Instituições envolvidas" | Parceiras formais, se houver |
| "Instituição de financiamento" | Agência + **natureza do financiamento** ("Bolsa", "Auxílio financeiro", "Cooperação"…). Código/processo é opcional; valor nunca é público |
| "Produção C&T" | Selecione produções já salvas em Produções que saíram do projeto |
| "Orientações" | Só para quem orienta |

## Passo a passo para quem tem bolsa num projeto

1. **Antes**, identifique o coordenador como coautor (menu lateral › "Identificar
   co-autor", pela lupa, por nome ou CPF). Assim, ao salvar o projeto, o coordenador recebe um
   e-mail para confirmar a participação, o que **certifica** o projeto. Avise o orientador.
2. Cadastre o projeto com o título oficial, "Em andamento", o orientador como coordenador e o
   financiador com a natureza "Bolsa" (ex.: CNPq – Bolsa; CAPES – Bolsa; FAP – Bolsa).
3. Cadastre as produções (resumos, apresentações, relatórios, software…) e depois volte ao
   projeto e selecione-as em "Produção C&T". A lista só mostra o que já foi salvo.

## Casos frequentes

- **Bolsa renovada no mesmo projeto**: uma entrada só, "Em andamento" desde o ano de início.
- **Projeto mudou de título no novo edital**: crie outra entrada; marque a antiga como
  "Concluído" se a pessoa saiu dela.
- **IC voluntária**: mesmo jeito, sem financiador (ou com a natureza que a universidade
  indicar, se houver programa institucional).
- **Projeto de extensão**: natureza "Extensão"; bolsa de extensão como financiamento
  "Bolsa" da agência/universidade.
- **Mestrado/doutorado**: o projeto da dissertação/tese pode entrar como projeto de pesquisa
  (coordenado pelo orientador), além da Formação. Muitos programas pedem isso para a Coleta
  CAPES; ver `pos-graduacao.md`.
- **Produção que não saiu do projeto**: não ligue. Ligar um relatório de outra instituição ao
  projeto da IC só faz sentido se a atividade estava no plano de trabalho.

## Erros comuns

- Projeto chamado "Iniciação Científica" ou "PIBIC".
- A pessoa marcada como coordenadora do projeto do orientador.
- Esquecer o financiador (ou pôr financiador que não financiou).
- Deixar "Em andamento" anos depois de acabar.
- Projeto salvo como "Privado" (não aparece no público nem na prévia).
