# Modelos de texto para copiar e adaptar

Troque tudo que está entre colchetes. Não invente dados: se faltar uma informação, pergunte.
Os modelos usam terceira pessoa, como é costume no Lattes.

## Resumo (Texto inicial)

**Graduação com IC**
```
Graduando(a) em [curso] pela [universidade] ([SIGLA]), com ingresso em [ano]. Desde [mês] de [ano], é bolsista de Iniciação Científica do [agência] ([programa]/[agência]/[SIGLA]) no projeto "[título do projeto]", sob orientação de [Prof./Profa. Dr./Dra. Nome], e integra o [nome do grupo] ([SIGLA da universidade]), na linha "[linha]". [Principais atividades e produções em uma ou duas frases.] [Outras experiências: monitoria, extensão, estágio.] [Formação anterior, idiomas, prêmios.]
```

**Mestrado/doutorado**
```
[Mestrando(a)/Doutorando(a)] em [área] pelo Programa de Pós-Graduação em [nome] da [universidade] ([SIGLA]), sob orientação de [Prof./Profa. Dr./Dra. Nome], com bolsa [agência]. Desenvolve pesquisa sobre [tema], no âmbito do [grupo/laboratório]. Graduado(a) em [curso] pela [universidade] ([ano]). [Principais publicações/apresentações/atividades.] [Docência, estágio docência, experiência profissional.] [Interesses de pesquisa.]
```

## Outras informações do vínculo de bolsista

```
Bolsa de Iniciação Científica do [agência] ([programa]/[agência]/[SIGLA]) no projeto "[título]", sob orientação de [Prof./Profa. Dr./Dra. Nome] ([grupo/unidade]). Vigência: [dd/mm/aaaa] a [dd/mm/aaaa]. Atividades: [lista curta do plano de trabalho].
```

Bolsa renovada no mesmo projeto (um vínculo só):
```
… Vigências: [início 1] a [fim 1] e, após renovação, [início 2] a [fim 2]. …
```

## Atividade de pesquisa (grupo)

```
Integrante do [nome do grupo] ([universidade]), grupo certificado no Diretório dos Grupos de Pesquisa do CNPq, na linha "[linha]", sob orientação de [Prof./Profa. Dr./Dra. Nome].
```

## Descrição de projeto

```
[Objetivo e tema do projeto em 2–4 frases, de preferência copiados do resumo oficial.] Participação como bolsista de [modalidade] ([programa]/[agência]) desde [mês/ano], com atividades de [lista].
```

## Produção com autoria institucional (relatório, dossiê)

```
Relatório de autoria institucional ([INSTITUIÇÃO A]; [INSTITUIÇÃO B]). [Cidade]: [editora/instituições], [ano]. Participação do titular deste currículo como membro da equipe de [função exatamente como na ficha], conforme a ficha editorial. [Link do PDF, sem http://]
```

## Organização de evento

```
Membro da equipe de organização do [nome oficial do evento], realizado de [datas] em [local, cidade]. Certificado emitido em [data]. Site do evento: [endereço sem http://]
```

## Software / plataforma

Finalidade (curta, ~250 caracteres):
```
Plataforma [web/app] para [função principal], desenvolvida no [grupo/unidade]. [Segunda frase com o uso principal].
```

Resumo:
```
O [nome] é [o que é], desenvolvido no [grupo/unidade] para [objetivo]. [O que permite fazer.] Foi desenvolvido no âmbito do projeto "[título]" ([programa]/[agência]), sob orientação de [Prof./Profa. Dr./Dra. Nome]. [Acesso: endereço, se público.]
```

## Traduções (inglês) — equivalências úteis

| Português | Inglês |
|---|---|
| Bolsista de Iniciação Científica | Undergraduate Research Fellow |
| Mestrando(a) / Doutorando(a) | Master's student / PhD student |
| Orientador(a) | Advisor / Supervisor |
| Grupo de pesquisa | Research group |
| Linha de pesquisa | Research line |
| Monitor(a) | Teaching assistant |
| Projeto de extensão | Community outreach (extension) project |
| Estágio | Internship |
| Equipe de organização | Organizing team |
| Relatório de pesquisa | Research report |

Títulos oficiais (projetos, eventos brasileiros) podem ficar em português nas traduções: não
invente traduções oficiais.
